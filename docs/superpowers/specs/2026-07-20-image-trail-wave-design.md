# Image Trail Wave Layout

## Goal

Replace the current mouse-generated Image Trail effect with a fixed horizontal image-card arrangement inspired by the supplied reference image. Keep the effect usable as a fillable gallery and visually consistent with the first six effects.

## Behavior

- Render every configured Image Trail slot as a persistent card.
- Arrange cards on one horizontal arc-like row: the center cards sit higher, while cards toward both edges sit progressively lower and may be naturally clipped by the canvas.
- Animate each card with a small vertical sine-like float. Use staggered delays so the row reads as one continuous soft wave rather than independent jumps.
- Remove pointer-generated cards, pointer movement handling, wheel handling, drag handling, and click-to-expand behavior from Image Trail.
- Preserve the existing play/pause state: pausing freezes the wave and resuming continues it.

## Visuals

- Keep the shared card treatment: rounded corners, thin border, filled image with `object-fit: cover`, and existing placeholder behavior.
- Keep the card dimensions responsive to the canvas size and aspect ratio.
- Reuse the existing ivory theme overrides so the cards, borders, grid, and shadows remain aligned with the other effects.
- Do not add reference-image text, decorative bubbles, or a new background treatment.

## Implementation Shape

- Change `renderImageTrail` to render the persistent card elements directly in a positioned stage.
- Replace `initImageTrails` with a small layout initializer that measures the container, sets responsive card variables, and assigns each card its horizontal offset, vertical arc position, scale, and animation delay.
- Keep the animation in CSS so it stays compositor-friendly and does not depend on pointer event frequency.
- Mirror the behavior in the published-preview inline script generated by `buildPublishedDocument`.
- Keep the change scoped to Image Trail; do not alter the existing Orbit Carousel, Circular Gallery, Card Totem, Mosaic Grid, Photo Orbit, or Scroll Morph logic.

## Validation

- Verify the Image Trail template renders all slots and no transient `.image-trail-item` nodes are created.
- Verify cards continue moving while playing and stop when paused.
- Verify pointer movement, wheel, and click do not create or expand cards.
- Verify 16:9, 4:3, 1:1, 4:5, and 9:16 canvas ratios without clipping the center cards.
- Verify editor and preview card sizes match.
- Verify ivory background styling remains aligned with the other effects.
